## 🧭 About me

I build tools that make other developers faster: libraries, CLIs, templates and UIs.
Lately I spend most of my time on **LLM / agent tooling**: SDKs built from scratch, local
inference helpers and chat/agent UI templates. Before that I worked a lot on the **.NET
ecosystem** (entity tooling, Blazor form builders, OpenAI clients) and **TypeScript**
runtimes and utilities.

- 🔭 Working on: agent SDKs, local-first AI tooling, desktop developer tools
- 🌱 Learning: Rust, agent architectures, local LLM inference
- 💬 Ask me about: .NET, TypeScript, LINQ-style APIs, LLM apps, Linux tooling
